# Inbox Work Guide

This folder contains lightweight working notes for day-to-day business operations, meetings, reviews, and improvement ideas.

## Recommended Structure

```text
Inbox/Work/
  README.md
  1on1/
    Team Members/
    Managers/
  Daily Reports/
  Improvement Ideas/
  Meetings/
  Operations/
    Administrative/
    Engineering Operations/
  Reviews/
```

## Folder Usage

- `1on1`: Notes from recurring one-on-one meetings.
- `Team Members`: Notes for one-on-ones that you lead with unit members.
- `Managers`: Notes for one-on-ones where you receive guidance from managers or supervisors.
- `Daily Reports`: Daily status notes, short summaries, and routine reporting drafts.
- `Improvement Ideas`: Quick notes about friction, concerns, and possible process improvements.
- `Meetings`: General meeting notes that do not belong to one-on-ones.
- `Operations`: Work procedures, manuals, and operational reference notes.
- `Administrative`: Administrative procedures such as attendance, expenses, and general office processes.
- `Engineering Operations`: Development-related operational procedures such as access requests, DB access, and other engineering support tasks.
- `Reviews`: Notes for evaluations, feedback cycles, and review preparation.

## Working Rule

- Keep this folder lightweight and action-oriented.
- Move long-lived or broadly reusable knowledge to the appropriate PARA folders when it becomes stable.
- Use subfolders only when they make retrieval easier.

This README is a simple guide for organizing work-in-progress notes under `Inbox/Work`.
